# B站视频关系图谱 - 使用说明

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 查看演示效果

使用示例数据快速生成演示图谱：

```bash
python test_demo.py
```

然后打开 `output/demo_graph.html` 查看效果。

### 3. 使用真实数据

#### 步骤1：RPA采集数据

使用你的RPA工具（如影刀）采集B站视频数据，参考 `RPA采集指南.md`。

采集完成后，将数据保存为 `data/videos.csv`，格式如下：

```csv
bv_id,title,up_name,publish_date,play_count,coin_count,duration,has_subtitle
BV1234567890,视频标题1,UP主A,2024-01-01,10000,500,3600,是
BV0987654321,视频标题2,UP主B,2024-01-02,20000,800,4200,否
```

#### 步骤2：生成图谱

```bash
python run.py
```

#### 步骤3：查看结果

打开 `output/graph.html` 即可查看交互式图谱。

## 图谱功能

### 交互操作

1. **拖拽节点**：可以自由拖动节点调整布局
2. **缩放**：鼠标滚轮缩放视图
3. **平移**：按住鼠标拖动背景平移视图
4. **点击高亮**：点击节点高亮其相关连接
5. **双击跳转**：双击视频节点跳转到B站
6. **搜索节点**：使用顶部下拉框搜索并定位节点
7. **重置视图**：点击"重置选择"按钮恢复初始状态

### 节点类型

- **核心节点**（红色）：主题中心
- **UP主节点**（绿色）：视频创作者
- **视频节点**（蓝色）：具体视频
  - 绿色边框：有字幕
  - 蓝色边框：无字幕
  - 节点大小：反映播放量

### 连接关系

- **实线粗线**：核心到UP主
- **实线细线**：UP主到视频
- **虚线**：同一UP主的视频之间

## 自定义配置

### 修改节点颜色

编辑 `src/graph_template.html`，找到 `groups` 配置：

```javascript
groups: {
    Core: {
        color: { background: '#FF6B6B', border: '#C92A2A' }
    },
    Video: {
        color: { background: '#4ECDC4', border: '#1E88E5' }
    },
    UP: {
        color: { background: '#95E1D3', border: '#38A169' }
    }
}
```

### 调整物理引擎

修改 `physics` 配置来改变节点布局：

```javascript
physics: {
    barnesHut: {
        gravitationalConstant: -8000,  // 引力常数（负值为斥力）
        springConstant: 0.04,          // 弹簧常数
        springLength: 95               // 弹簧长度
    }
}
```

### 修改节点大小计算

编辑 `src/data_processor.py`，找到节点大小计算：

```python
# 根据播放量计算节点大小
size = min(50, 20 + int(row['play_count'] / 1000))
```

## 高级功能

### 添加主题分类

如果你的数据包含主题分类，可以创建主题节点：

1. 在CSV中添加 `category` 字段
2. 修改 `src/data_processor.py` 添加主题节点创建逻辑
3. 建立视频到主题的连接

### 时间轴筛选

可以添加时间轴控件，按发布日期筛选视频：

1. 在HTML模板中添加日期选择器
2. 使用vis.js的过滤功能动态显示/隐藏节点

### 数据统计

在图谱页面添加统计面板：

- 总视频数
- 总播放量
- UP主数量
- 平均播放量

## 常见问题

### Q: 图谱加载很慢？

A: 如果节点数超过500个，建议：
- 减少物理引擎迭代次数
- 使用分页或筛选功能
- 考虑使用服务器端渲染

### Q: 节点重叠严重？

A: 调整物理引擎参数：
- 增大 `springLength`
- 减小 `gravitationalConstant`（更负）

### Q: 如何导出图片？

A: 在浏览器中：
1. 右键点击图谱
2. 选择"检查"打开开发者工具
3. 在Console中输入：
```javascript
var canvas = document.querySelector('canvas');
var url = canvas.toDataURL('image/png');
var link = document.createElement('a');
link.download = 'graph.png';
link.href = url;
link.click();
```
