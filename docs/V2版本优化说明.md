# V2版本优化说明

## 概述

V2版本对项目进行了架构优化，主要改进包括：

1. **节点配置JSON化** - 提高可复用性和可配置性
2. **数据格式标准化** - 统一的图谱数据格式
3. **采集模块专门对接** - 直接生成图谱所需的数据格式
4. **配置与代码分离** - 更易于维护和扩展

## 核心改进

### 1. JSON配置系统

#### 节点配置 (`config/node_config.json`)

定义了所有节点类型的样式配置：

```json
{
  "node_types": {
    "Core": {
      "shape": "dot",
      "size": 30,
      "color": {...},
      "font": {...}
    },
    "Video": {...},
    "UP": {...},
    "Lecture": {...},  // 新增：讲座系列节点
    "Reference": {...}  // 新增：参考文献节点
  },
  "edge_types": {
    "video_to_up": {...},
    "core_to_video": {...},
    "lecture_to_video": {...},  // 新增
    "video_to_reference": {...}  // 新增
  }
}
```

**优势**：
- 无需修改代码即可调整样式
- 支持新增节点类型
- 配置集中管理

#### 数据格式规范 (`config/graph_schema.json`)

定义了标准的图谱数据格式：

```json
{
  "nodes": [
    {
      "id": "BV1234567890",
      "label": "视频标题",
      "group": "Video",
      "metadata": {
        "play_count": 10000,
        "like_count": 500,
        ...
      }
    }
  ],
  "edges": [
    {
      "from": "BV1234567890",
      "to": "UP_123456",
      "type": "video_to_up"
    }
  ],
  "metadata": {
    "title": "图谱标题",
    "total_videos": 100,
    ...
  }
}
```

**优势**：
- 数据格式统一
- 易于验证和调试
- 支持元数据扩展

### 2. 数据处理器V2 (`src/data_processor_v2.py`)

#### 主要特性

1. **基于配置的节点生成**
   ```python
   processor = DataProcessorV2()
   processor.load_from_csv('data/videos.csv', core_keyword='站桩')
   ```

2. **支持多种节点类型**
   ```python
   # 添加讲座系列
   processor.add_lecture_series('入门系列', ['BV1', 'BV2', 'BV3'])
   
   # 添加参考文献
   processor.add_reference('《站桩功》', '书籍', ['BV1', 'BV2'])
   ```

3. **灵活的数据源**
   ```python
   # 从CSV加载
   processor.load_from_csv('data/videos.csv')
   
   # 从JSON加载
   processor.load_from_json('data/graph_data_v2.json')
   ```

4. **自动应用样式**
   ```python
   processor.apply_edge_styles()  # 根据配置应用边样式
   ```

#### 节点大小计算

支持线性和对数缩放：

```python
size = processor._calculate_node_size(
    value=play_count,
    min_size=15,
    max_size=40,
    min_value=df['play_count'].min(),
    max_value=df['play_count'].max(),
    scale='log'  # 或 'linear'
)
```

### 3. 采集器V2 (`src/bilibili_crawler_v2.py`)

#### 直接输出图谱格式

```python
crawler = BilibiliCrawlerV2()
```

## 性能优化

```python
# 缓存处理后的数据
processor.save_json('data/graph_data_v2.json')

# 下次直接加载
processor.load_from_json('data/graph_data_v2.json')
```

### 2. 增量更新

```python
# 只更新新增的视频
new_videos = crawler.batch_get_videos(new_bv_list)

processor.add_videos(new_videos)
processor.save_json('data/graph_data_v2.json')
```

### 3. 配置预加载

```python

config = load_config('config/node_config.json')
processor = DataProcessorV2(config=config)
```

## 迁移指南

### 从V1迁移到V2

1. **数据迁移**
   ```bash
   # 使用V2数据处理器转换现有CSV
   python -c "from src.data_processor_v2 import DataProcessorV2; \
              DataProcessorV2().load_from_csv('data/videos.csv').save_json('data/graph_data_v2.json')"
   ```

2. **配置迁移**
   - V1的配置在 `src/config.py`
   - V2的配置在 `config/node_config.json`
   - 手动将样式配置转换为JSON格式

3. **代码迁移**
   - 替换 `DataProcessor` 为 `DataProcessorV2`
   - 替换 `GraphGenerator` 为 `GraphGeneratorV2`
   - 更新模板路径

### 兼容性

V2版本保持向后兼容：

- 仍支持CSV格式输入
- 可以生成V1格式的输出
- 配置文件可选（有默认值）

## 总结

V2版本的主要优势：

1. ✅ **配置驱动** - 无需修改代码即可调整样式
2. ✅ **数据标准化** - 统一的数据格式，易于集成
3. ✅ **模块解耦** - 采集、处理、生成独立
4. ✅ **易于扩展** - 支持新节点类型和数据源
5. ✅ **向后兼容** - 可与V1版本共存

建议新项目使用V2版本，现有项目可逐步迁移。
