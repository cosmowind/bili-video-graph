## 典型使用场景

### 场景1：第一次使用（推荐增强版）

1. 阅读 [README.md](../README.md)
2. 安装依赖：`pip install -r requirements.txt`
3. 运行演示：`python test_demo.py`
4. 生成增强版：`python run_enhanced.py`
5. 查看效果：打开 `output/graph_enhanced.html`

### 场景2：采集真实数据

1. 测试API：`python test_api.py`
2. 运行采集工具：`python crawl.py`
3. 选择采集模式（关键词或BV号列表）
4. 等待采集完成
5. 生成增强版：`python run_enhanced.py`
6. 查看：`output/graph_enhanced.html`

### 场景3：自定义样式

1. 阅读 [使用说明.md#自定义配置](使用说明.md#自定义配置)
2. 编辑 `src/config.py` 修改配置
3. 或编辑 `src/graph_template.html` 修改模板
4. 重新运行：`python run.py`

### 场景4：添加新功能

1. 阅读 [项目结构说明.md](项目结构说明.md)
2. 阅读 [项目总结.md#后续优化方向](项目总结.md#后续优化方向)
3. 在 `src/` 中添加代码
4. 更新相关文档

### 场景5：问题排查

1. 查看终端错误信息
2. 阅读 [使用说明.md#常见问题](使用说明.md#常见问题)
3. 检查数据格式是否正确
4. 确认依赖是否安装完整

## 快速命令

```bash
# 安装依赖
pip install -r requirements.txt

# 测试API连接
python test_api.py

# 采集数据（交互式）
python crawl.py

# 查看演示
python test_demo.py

# 生成基础版图谱
python run.py

# 生成增强版图谱（推荐）
python run_enhanced.py

# 查看项目结构
tree /F  # Windows
ls -R    # Linux/Mac
```
