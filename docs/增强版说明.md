# 增强版图谱说明

## 概述

增强版图谱在基础版的基础上，添加了右侧边栏和排行榜功能，提供更丰富的数据展示和交互体验。

## 功能对比

| 功能 | 基础版 | 增强版 |
|------|--------|--------|
| 交互式图谱 | ✅ | ✅ |
| 节点高亮 | ✅ | ✅ |
| 双击跳转B站 | ✅ | ✅ |
| 右侧边栏 | ❌ | ✅ |
| 视频详情展示 | ❌ | ✅ |
| 封面显示 | ❌ | ✅ |
| TOP 10排行榜 | ❌ | ✅ |
| 多维度排名 | ❌ | ✅ |

## 增强版特性

### 1. 右侧边栏

点击任意视频节点，右侧边栏会显示：

- **视频封面**：自动加载B站封面图
- **基本信息**：
  - UP主名称
  - 发布日期
  - 字幕状态
- **统计数据**：
  - ▶ 播放量
  - ❤ 点赞数
  - 🪙 投币数
  - ⭐ 收藏数
- **视频简介**：前200字符
- **快速跳转**：点击按钮直达B站

### 2. TOP 10排行榜

提供4种排行维度：

#### 总播放
- 按播放量降序排列
- 展示最受欢迎的视频

#### 赞/播比
- 点赞数 / 播放量 × 100%
- 反映视频质量和观众认可度

#### 币/播比
- 投币数 / 播放量 × 100%
- 反映观众的深度认可

#### 综合转化
- (点赞数 + 投币数 + 收藏数) / 播放量 × 100%
- 综合评估视频的互动质量

### 3. 交互增强

- **点击节点**：查看视频详情
- **点击排行榜**：跳转到对应节点并高亮
- **双击节点**：直接打开B站视频页面

## 使用方法

### 生成增强版图谱

```bash
python run_enhanced.py
```

### 查看结果

打开 `output/graph_enhanced.html` 即可查看增强版图谱。

## 技术实现

### 数据处理

`src/graph_generator_enhanced.py` 负责：

1. 加载图谱数据（节点和边）
2. 加载视频详细信息
3. 计算各种排行榜
4. 渲染HTML模板

### 前端交互

`src/graph_template_enhanced.html` 实现：

1. 侧边栏UI布局
2. 排行榜切换逻辑
3. 节点点击事件处理
4. 数据动态更新

### 关键函数

- `djhUpdateSidebar(bvid)` - 更新侧边栏内容
- `djhShowRank(type, btn)` - 切换排行榜类型
- `djhOpenVideo()` - 打开B站视频

## 性能优化

- 使用JSON格式存储视频详情，快速查询
- 排行榜数据预计算，避免实时计算
- 图片懒加载，减少初始加载时间

## 常见问题

### Q: 封面图片无法显示？

A: B站封面URL可能需要特殊处理，当前使用通用格式。如果无法显示，会自动隐藏封面区域。

### Q: 排行榜数据不准确？

A: 排行榜基于采集时的数据计算，如需更新请重新采集数据。

### Q: 如何自定义排行榜？

A: 修改 `src/graph_generator_enhanced.py` 中的 `calculate_rankings()` 方法，添加新的排名维度。
